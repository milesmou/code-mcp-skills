# Code Skill

通过按需加载的模块处理代码质量任务。当前提供 Clean Code 审查与渐进改进规划。

## 模块索引

| 模块 | 适用任务 | 入口 |
| --- | --- | --- |
| `clean-code-reviewer` | 代码审查、可读性与可维护性分析、重构建议、遗留代码改进计划 | [Clean Code Reviewer](modules/clean-code-reviewer/module.md) |

## 使用方式

1. 确定用户提供的代码、语言、审查范围与目标；已有上下文足够时直接开始。
2. 执行代码审查或改进规划前，读取上表中的模块入口；参考资料与脚本按模块说明选用。
3. 遵循目标项目的语言惯例和团队约定，根据实际影响提出建议，避免机械套用规则。

模块中的相对链接以该模块文档所在目录为基准解析。
